# Как собрать .apk из «Горного байкера»

Игра написана на Python (pygame-ce + pymunk + numpy). Сборка под Android
делается через **Buildozer + python-for-android**, и она работает **только
в Linux**. На Windows APK напрямую не собрать — есть два пути ниже.

Я уже подготовил всё нужное в этой папке:

| Файл | Зачем |
|------|-------|
| `buildozer.spec` | Конфиг сборки (пакет, библиотеки, параметры) |
| `main.py` | Точка входа приложения под Android |
| `.github/workflows/build-apk.yml` | Автосборка в облаке GitHub |
| `mountain_rider.py` | игра (уже адаптирована под сенсор и Android) |

---

## Путь 1 — облачная сборка через GitHub Actions (без Linux у вас) — ЛЕГЧЕ ВСЕГО

1. Заведите репозиторий на GitHub (бесплатно) и залейте туда эту папку
   (пустую папку `assets` можно не заливать — игра сама нарисует картинки
   при первом запуске, но лучше залить с уже готовыми картинками, чтобы не ждать).
2. На вкладке **Actions** появится workflow **"Build Android APK"**.
3. Нажмите **Run workflow** (и запуск вручную, и при `push` в `main`).
4. Через ~15–40 минут внизу будет артефакт **mountain-rider-apk** — внутри лежит
   готовый `.apk`. Скачайте его, перенесите на телефон и установите
   (разрешите установку из неизвестных источников).

> Бесплатно: у GitHub есть лимит на минуты сборки для приватных репозиториев
> (~2000 мин/мес на аккаунт), для открытых — безлимит.

## Путь 2 — сборка на своём Linux/WSL (полный контроль)

1. Подготовить окружение:
   ```bash
   sudo apt update
   sudo apt install -y git zip unzip curl wget \
     python3-pip python3-venv \
     autoconf automake libtool pkg-config \
     zlib1g-dev libncurses5-dev libncursesw5-dev libtinfo5 \
     cmake libffi-dev libssl-dev libltdl-dev openjdk-17-jdk
   pip install --user --upgrade buildozer cython
   ```
2. Зайти в папку игры (в WSL она лежит по пути вроде
   `/mnt/c/Users/Пользователь/Downloads/mountain_rider`).
3. Собрать:
   ```bash
   export PATH="$HOME/.local/bin:$PATH"
   buildozer android debug
   ```
4. Готовый файл появится в `bin/`:
   ```bash
   ls -la bin/
   ```

> Первый запуск долгий и качает много гигабайт (SDK/NDK). Дальше — быстрее.

## Что может пойти не так (и как чинить)

- **Ошибка про JDK** — нужен OpenJDK 17 (`openjdk-17-jdk`), не 21+ и не 8.
- **`pymunk` не собирается под ARM** — у pymunk есть чистая Python-реализация
  без компиляции. Если recipe падает, замените в `buildozer.spec`
  `pymunk` на отдельный вариант (см. документацию pymunk про pure-python),
  либо переведите игру на чистый каркас без pymunk. Вероятнее всего рецепт
  p4a соберётся сам.
- **Очень маленькие/большие кнопки** — подгоняйте интерактивные зоны в
  `mountain_rider.py` под свой экран.
- **Игра запускается, но чёрный экран** — смотрите лог: он выводится в logcat
  (в spec включён `android.logcat = 1`).

## Готовые для релиза (Google Play и т.п.)

Этот конфиг собирает **debug**-APK (подписан тестовым ключом, доступен
для ручной установки). Для публикации нужен `release`-сборка со своим
ключом подписи — скажите, если понадобится, я подготовлю шаги.
