ГОРНЫЙ БАЙКЕР
=============

Установка (один раз):
    py -m pip install pygame-ce pymunk numpy pillow

Запуск (командная строка должна быть открыта в этой папке):
    py mountain_rider.py

Управление:
    D / стрелка вправо - газ        A / стрелка влево - тормоз
    W / стрелка вверх  - наклон назад   S / стрелка вниз - наклон вперёд
    M / кнопка "Магазин" - открыть магазин улучшений
    F1 / кнопка "Админ" - админ-панель (настройка физики)
    R - с контрольной точки после падения   N - заново   F2 - качество графики

Админ-панель (F1):
    Прямое регулирование - игровая пауза, значения применяются сразу:
      - Гравитация (+/- 50)
      - Макс. скорость колёс (+/- 5)
      - Ускорение / момент двигателя (+/- 5000)
      - Наклон / LEAN (+/- 5000)
      - Очки (+/- 100) - для быстрых покупок в магазине
      - "СБРОСИТЬ НАСТРОЙКИ" - вернуть значения магазина/по умолчанию
    Только пока открыта панель - при закрытии настройки сохраняются на сессию.

Магазин улучшений:
    Очки зарабатываются за дистанцию, кувырки и контрольные точки.
    Купить можно (очки тратятся сразу):
      - Скорость  - повышает максимальную скорость колеса (до 5 уровней)
      - Ускорение - повышает силу двигателя / разгон (до 5 уровней)
      - Гравитация - разовая покупка, снижает гравитацию (1100 -> 880),
        полёты дольше и кувырки проще
    Пока открыт магазин, игра на паузе.

Как поменять картинки:
    Все картинки лежат в папке assets (PNG с прозрачным фоном).
    Откройте любую в Krita / GIMP / Photoshop, поправьте и сохраните под тем же именем -
    игра подхватит её. Размеры менять не нужно.
    Детали байка и гонщика нарисованы в 3 раза крупнее игрового размера (для чёткости).
    Если удалить папку assets, игра сама нарисует все картинки заново (make_assets.py).
